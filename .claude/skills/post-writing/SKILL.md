# Написание постов
**Структура:** Хук (1 строка) → Развитие (проблема/история) → Ценность (3–5 пунктов) → Вывод → CTA.
**Формулы хуков:** «Я потратил X, чтобы понять Y», «3 ошибки, из-за которых…», «Перестаньте делать X», «Как я получил X за Y без Z», вопрос-боль, цифра-шок.
**Формулы текста:** AIDA, PAS, BAB, 4U.
**Под площадку:**
- Instagram — до 2200 симв., первые 125 видны, абзацы, эмодзи-маркеры, 3–10 хештегов.
- TikTok — коротко, текст дополняет видео.
- Telegram — форматирование, 500–1500 симв., одна мысль.
- LinkedIn — короткие строки, без хештег-спама, вопрос в конце.
- Facebook — сторителлинг, вовлекающий вопрос.
**Чек-лист:** хук цепляет? одна мысль? нет воды? есть CTA? соответствует tone of voice? нет ошибок?
