# Сценарий видео
## Короткое (15–45 сек)
| Время | Кадр/действие | Текст на экране | Закадр/реплика | Звук/музыка |
- 0–3 с: хук (визуальный разрыв шаблона + текст-обещание)
- 3–25 с: ценность быстрыми склейками каждые 1–3 с
- финал: payoff + CTA или зацикливание на начало
## YouTube (8–15 мин)
Хук и обещание (0–30 с) → вступление/контекст → блоки по 1–2 мин с открытыми петлями → кульминация → итог → CTA (подписка, следующее видео).
Добавь: варианты названий (3), ТЗ на превью, описание с таймкодами.
