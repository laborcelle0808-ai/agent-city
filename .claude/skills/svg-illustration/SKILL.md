# SVG-иллюстрация
1. Набросок композиции: силуэт читается в чёрно-белом варианте.
2. Палитра 3–6 цветов + тени/блики как отдельные слои.
3. Структура: `<g id="character"><g id="head">…` — понятные id для анимации; viewBox без фиксированных width/height.
4. Формы: path с кривыми Безье, простые примитивы, градиенты (linear/radial), clipPath/mask для деталей.
5. Иконки: сетка 24×24, stroke-width 1.5–2, stroke-linecap round, единый стиль.
6. Проверка: рендер в PNG через Playwright, просмотр на светлом и тёмном фоне, оптимизация svgo.
