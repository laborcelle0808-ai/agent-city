# Тестирование API
**Для каждого эндпоинта:** 2xx на валидных данных · 400/422 на невалидных · 401 без токена · 403 с чужим токеном (BOLA) · 404 на несуществующем · граничные значения · дубли/идемпотентность · схема ответа · время ответа.
**Инструменты:** Playwright `request` · pytest + httpx · Postman/newman · Schemathesis (`schemathesis run openapi.json --base-url ...`) для фаззинга.
**Контракты:** схема OpenAPI — единый источник правды, проверка ответов zod/JSON Schema.
**Отчёт:** таблица | Эндпоинт | Кейс | Ожидалось | Получено | Статус |.
