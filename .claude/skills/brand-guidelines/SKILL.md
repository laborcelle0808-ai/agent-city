# Брендбук
1. **Суть бренда**: миссия, ценности, характер, позиционирование.
2. **Логотип** (SVG): основная, горизонтальная, знак, монохром; охранное поле, минимальный размер, запреты.
3. **Цвета**: основной, акцент, 3–5 нейтральных — HEX / RGB / CMYK; контраст текста ≥ 4.5:1.
4. **Типографика**: заголовочный + наборный шрифт (Google Fonts с кириллицей: Montserrat, Manrope, Inter, Unbounded, Golos, Onest, Rubik), шкала размеров.
5. **Графика**: паттерны, иконки, стиль фото/иллюстраций.
6. **Tone of voice**: принципы и примеры.
7. **Носители**: аватар, обложки соцсетей, визитка, шаблоны постов.
Результат — HTML-страница брендбука + папка ассетов.
