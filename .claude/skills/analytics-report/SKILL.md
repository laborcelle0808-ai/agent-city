# Отчёт по аналитике
**Формулы:** ER by reach = вовлечения / охват × 100%; ERR (Telegram) = просмотры / подписчики × 100%; CTR = клики / показы; CPM = расход / показы × 1000; CPL = расход / лиды; ROMI = (доход − расход) / расход × 100%.
**Структура:**
1. Резюме в 3 строках.
2. Ключевые метрики: таблица | Метрика | Прошлый период | Текущий | Δ% |.
3. Топ-3 и антитоп-3 публикаций с причинами.
4. Реклама: расход, лиды, CPL, ROAS по кампаниям.
5. Выводы и гипотезы.
6. План на следующий период.
Для данных из CSV/XLSX используй Python (pandas, matplotlib) и сохраняй графики в PNG.
