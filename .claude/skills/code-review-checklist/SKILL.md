# Чек-лист код-ревью
- [ ] Код делает то, что требуется; крайние случаи (пусто, null, большие данные, ошибки сети)
- [ ] Обработка ошибок и понятные сообщения
- [ ] Нет секретов в коде, ввод валидируется, нет SQL-инъекций/XSS
- [ ] Читаемость: имена, размер функций, нет дублирования
- [ ] Производительность: нет N+1, лишних ререндеров, тяжёлых циклов
- [ ] Типы (TypeScript/typing), линтер без ошибок
- [ ] Тесты на новую логику
- [ ] Доступность и адаптив (для фронта)
- [ ] README/комментарии там, где логика неочевидна
