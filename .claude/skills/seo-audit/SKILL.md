# SEO-аудит
1. **Техническое**: robots.txt, sitemap.xml, коды ответов, редиректы, canonical, HTTPS, мобильная версия, дубли, hreflang.
2. **Скорость**: Core Web Vitals (Lighthouse через Playwright/Chromium).
3. **On-page** по каждой странице: title, description, H1 (один), структура H2–H3, alt, ЧПУ, внутренние ссылки.
4. **Разметка**: schema.org (Organization, LocalBusiness, Product, FAQ, Article).
5. **Контент**: соответствие интенту, объём, уникальность, E-E-A-T.
6. **Семантика**: недостающие кластеры → новые страницы.
7. **Отчёт**: | Проблема | Страница | Приоритет | Как исправить |.
