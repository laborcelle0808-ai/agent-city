# Отчёт об уязвимостях
**Резюме:** scope, даты, количество находок по severity (Critical/High/Medium/Low/Info), общий вывод.
**Для каждой находки:**
- Название и ID (VULN-001)
- Severity + CVSS 3.1/4.0 вектор
- Где: URL/эндпоинт/файл:строка
- Описание и причина (CWE)
- Шаги воспроизведения
- PoC (запрос/скрипт, без вредоносной нагрузки)
- Влияние на бизнес
- Исправление: конкретный код/конфиг + ссылка (OWASP Cheat Sheet)
- Статус ретеста
**Приложение:** использованные инструменты, ограничения тестирования.
