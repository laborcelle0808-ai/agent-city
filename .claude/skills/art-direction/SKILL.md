# Арт-дирекшн
1. **Инсайт и идея**: одна фраза — что должен почувствовать зритель.
2. **Мудборд**: 8–12 референсов (Awwwards, Behance, Godly, Dribbble) с пояснением, что берём из каждого.
3. **3 направления**: например, «редакционный минимализм», «смелый брутализм», «тёплое иллюстративное». Для каждого — палитра, шрифты, приём, пример экрана.
4. **Система**: сетка, шкала типографики, цвет (60/30/10), стиль изображений, моушн-принципы.
5. **Ревью-чек-лист**: иерархия читается за 3 секунды · один главный акцент на экран · выравнивание по сетке · ритм отступов · не больше 2 шрифтов · контраст · воздух · детали (иконки, состояния, микроанимации) · консистентность.
6. Всегда смотри на результат скриншотом (Playwright, 1440 и 375), а не только в коде.
