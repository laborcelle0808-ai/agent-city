# Стратегия тестирования
1. **Объект и риски:** ключевые функции, что сломается дороже всего.
2. **Виды тестов:** unit · integration · API · e2e · визуальные · производительность · доступность · безопасность · юзабилити.
3. **Пирамида:** много unit, меньше integration, мало, но критичных e2e.
4. **Окружения и данные:** local/staging, тестовые аккаунты, тестовые платежи.
5. **Матрица устройств:** Chrome/Safari/Firefox, iOS/Android, 375/768/1440.
6. **Критерии готовности:** 0 Critical/High багов · e2e критичных сценариев зелёные · Lighthouse ≥ 90 · axe без серьёзных нарушений · безопасность проверена.
7. **Отчёт:** таблица результатов + вердикт Go/No-Go.
